# Long-Term Research & Model Evolution Roadmap

## Strategic Vision
Build a clean, modular custom transformer implementation and AI Operating System runtime designed to evolve into a long-term research platform.

## Model Progression Milestones

```
+-------------------------------------------------------------------+
| Jarvis-0 (Proof of Concept)                                       |
| - Parameters: ~5M - 10M                                           |
| - Architecture: Decoder-only Transformer, 6 layers, 8 heads       |
| - Context Window: 512 tokens                                      |
| - Goal: Validate native end-to-end training & inference runtime   |
+-------------------------------------------------------------------+
                                 |
                                 v
+-------------------------------------------------------------------+
| Jarvis-1 (Small Engine)                                           |
| - Parameters: ~50M - 100M                                         |
| - Architecture: SwiGLU, RoPE, Grouped-Query Attention (GQA)      |
| - Context Window: 2048 tokens                                     |
| - Goal: Improved code generation & instruction following          |
+-------------------------------------------------------------------+
                                 |
                                 v
+-------------------------------------------------------------------+
| Jarvis-2 (Intermediate Engine)                                    |
| - Parameters: ~300M - 700M                                        |
| - Architecture: Mixture-of-Experts (MoE) / State Space Model      |
| - Context Window: 8192 tokens                                     |
| - Goal: Complex multi-agent reasoning & terminal automation       |
+-------------------------------------------------------------------+
                                 |
                                 v
+-------------------------------------------------------------------+
| Jarvis-X (Advanced Research Platform)                             |
| - Continuous self-contained fine-tuning, RAG, Speculative Decoding|
+-------------------------------------------------------------------+
```
